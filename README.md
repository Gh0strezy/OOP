# ООП — Лабораторные работы

Репозиторий с лабораторными работами по дисциплине "Объектно-ориентированное программирование" (C++).

## Структура репозитория

### [lab1/](lab1/) — Указатели и ссылки в C++
Работа с памятью: статический массив, динамический массив, `SafeArray`, матрица.

### [lab2/](lab2/) — Классы в C++
Электронный кошелёк `Wallet` с инкапсуляцией, конструкторами и методами (вариант 11).

### [lab3/](lab3/) — Перегрузка операторов
Матричный калькулятор 2×2 `Matrix` с арифметическими операциями и потоковым вводом/выводом (вариант 3).

### [lab4/](lab4/) — Наследование и полиморфизм
Иерархия транспортных средств: `Vehicle` → `LandVehicle` → `Car`/`Truck`/`Minivan`.

**Ключевые концепции:**
- 3 уровня наследования с абстрактным базовым классом
- Виртуальное наследование (решение проблемы "алмаза")
- Множественное наследование (`Minivan` от `Car` + `ICargoCarrier`)
- Чисто виртуальные функции и полиморфизм
- Статические члены и статические функции
- Дружественная функция с доступом к `private` полям
- Конструктор копирования и оператор присваивания
- Статические и динамические библиотеки (`liblab4.a`, `liblab4.so`)
- Сериализация/десериализация объектов в файл

**Вариант 2:** Легковой автомобиль, грузовик, минивэн с интерфейсами перевозки пассажиров и грузов.

---

Подробности по каждой работе — в `README.md` внутри соответствующей папки.

## Компиляция

Все проекты используют стандарт **C++14** с компилятором **g++**:

```bash
g++ -std=c++14 -Wall -Wextra <source_files>
```

Каждая лабораторная содержит инструкции по сборке в своём README.
