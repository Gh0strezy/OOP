# Лабораторная работа №1 — Указатели и ссылки в C++

Папка содержит 4 задания. Каждое задание — отдельный файл в своей подпапке.
Все команды ниже выполняются из этой папки (`lab1/`).

## Компиляция (C++14)

```bash
g++ -std=c++14 -Wall -Wextra -o task1 task1/task1.cpp
g++ -std=c++14 -Wall -Wextra -o task2 task2/task2.cpp
g++ -std=c++14 -Wall -Wextra -o task3 task3/task3.cpp
g++ -std=c++14 -Wall -Wextra -o task4 task4/task4.cpp
```

## Структура

- `task1/` — статический массив, функции по ссылке
- `task2/` — динамический массив, new/delete, ссылка на указатель
- `task3/` — структура SafeArray, безопасный доступ к элементам
- `task4/` — двумерный динамический массив (матрица оценок)
