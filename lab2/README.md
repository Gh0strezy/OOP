# Лабораторная работа №2 — Классы в C++. Вариант 11: электронный кошелёк (Wallet)

Все команды выполняются из этой папки (`lab2/`).

## Сборка и запуск (C++14)

```bash
g++ -std=c++14 -Wall -Wextra -o wallet Wallet.cpp main.cpp
./wallet
```

## Структура

- `Wallet.h` — объявление классов `Wallet` и `Owner` (владелец, хранится внутри `Wallet`) и перечисления `Currency`
- `Wallet.cpp` — реализация классов `Wallet` и `Owner`
- `main.cpp` — тестирование класса (создание, корректные/некорректные операции, независимость объектов)
- `diagrams/wallet_class.puml` — диаграмма классов (PlantUML)
- `Doxyfile` — конфигурация Doxygen

## Этап 1. Определение сущности

| Вопрос | Ответ |
|---|---|
| Что представляет собой объект? | Электронный кошелёк пользователя, хранящий денежные средства в одной валюте |
| Какие данные характеризуют объект? | Владелец (отдельный класс `Owner`: имя и email), баланс, валюта, количество операций, признак блокировки |
| Какие действия можно выполнять с объектом? | Пополнять, снимать, переводить на другой кошелёк, блокировать/разблокировать, выводить информацию |
| Какие состояния недопустимы? | Отрицательный баланс; операция с нулевой/отрицательной суммой; снятие или перевод с заблокированного кошелька; снятие суммы больше баланса; перевод между кошельками разных валют |

## Этап 2. Проектирование класса

| Элемент | Описание |
|---|---|
| Имя класса | `Wallet` |
| Поля | `owner` (`Owner` — **объект другого класса**, композиция), `balance` (`double`), `currency` (`Currency` — пользовательский `enum class`), `transactionCount` (`int`), `blocked` (`bool`), статическое `objectCount` (`int`) |
| Конструкторы | `Wallet()`; `Wallet(const Owner&, currency)`; `Wallet(const Owner&, initialBalance, currency)` — все через список инициализации |
| Методы чтения | `getOwner()`, `getBalance()`, `getCurrency()`, `getTransactionCount()`, `isBlocked()`, `printInfo()` — все `const` |
| Методы изменения | `deposit()`, `withdraw()`, `transferTo()`, `block()`, `unblock()` |
| Инварианты | 1) `balance >= 0`; 2) сумма операции `> 0`; 3) снятие/перевод запрещены при блокировке; 4) нельзя снять больше, чем есть на балансе; 5) перевод только между кошельками одной валюты |

### Вложенный класс `Owner`

`Wallet` хранит `Owner` по значению (композиция, на диаграмме — закрашенный ромб): владелец
создаётся и уничтожается вместе с кошельком, а копия внутри кошелька независима от исходного объекта.

| Элемент | Описание |
|---|---|
| Поля | `name` (`std::string`), `email` (`std::string`) |
| Конструкторы | `Owner()`; `Owner(name)`; `Owner(name, email)` |
| Методы | `getName()`, `getEmail()`, `hasEmail()` — `const`; `changeEmail()` — изменение |
| Инварианты | имя не пустое (иначе `"Unknown"`); email пустой либо корректный (`@` с непустыми частями) |

## Этап 3. Тестирование (`main.cpp`)

1. Создание трёх объектов тремя разными конструкторами
2. Вывод начального состояния
3. Корректные операции (пополнение, снятие, перевод)
4. Некорректные операции (отрицательная сумма, нехватка средств, заблокированный кошелёк, перевод между разными валютами)
5. Повторный вывод состояния — объекты остались корректными
6. Проверка независимости: изменение `w1` не влияет на `w2` и `w3`; смена email у исходного `alice` не меняет `Owner` внутри `w2`
