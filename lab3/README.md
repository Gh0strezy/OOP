## Класс Matrix

Матрица 2x2 хранится в `double data[2][2]`. Для каждой матрицы ведётся история операций,
которую можно вывести методом `printHistory()`.

История хранится в **массиве фиксированного размера** `std::string history[32]` (`std::vector`
и другие контейнеры не используются, динамической памяти нет). Когда массив заполнен, самая
старая запись вытесняется, а нумерация продолжается: `historyTotal` помнит, сколько операций
записано за всё время.

### Как работает деление

`A / B` = `A * B^(-1)`. Обратная матрица считается по формуле `(1/det) * [[d, -b], [-c, a]]`.
Если `det(B) = 0`, деление отклоняется: печатается ошибка, `A` не меняется, в историю идёт запись об отказе.

### Как работает сравнение

Операторы сравнивают **определители** (допуск `1e-9`). Поэтому матрицы `[[1, 2], [3, 4]]` и
`[[2, 0], [0, -1]]` считаются равными: у обеих определитель равен -2.

### Бинарные операторы через составные

```cpp
Matrix operator+(Matrix lhs, const Matrix& rhs)
{
    lhs += rhs;      // используется уже готовая логика
    return lhs;
}
```

Левый операнд принимается **по значению** — это копия, которую можно менять, не затрагивая оригинал.
